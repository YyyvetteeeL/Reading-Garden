## Reading-Garden
An interactive reading journal.

# Start
A few days ago, I finished reading Raymond Chandler’s *The Long Goodbye*, and suddenly, I couldn’t recall how many books I had completed so far this year. It occurred to me that it would be great to have a website where I could log the books I’ve read and visualize that collection. That is how this project came to be.

# 10.25
Today, I set up the basic framework for the website and implemented features to add and delete book records. Next, I plan to add a feature where a flower is "planted" in a "reading garden" for every book read.
