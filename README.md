## Reading-Garden
An interactive reading journal.

# Design Philosophy
This is a website for tracking your reading, designed to help users organize and record their reading progress, and to encourage the development of a consistent reading habit.

# Target Users
My target users are avid readers who wish to cultivate a consistent reading habit and need to keep a record of their reading, as well as those who enjoy tracking their reading progress through visual means.

# Main Features and Interactions
Key features include: adding books, updating reading progress, modifying reading status; searching for books; tracking reading progress, maintaining a daily reading log (reading calendar), and generating monthly reports; and visualizing a "reading garden."
The primary user workflow is as follows: the user adds a book → updates their reading progress → the system automatically synchronizes the bookshelf, calendar, reading garden, and monthly reports.

# Technical Implementation
Reading Garden is built using native HTML, CSS, and JavaScript, without a frontend framework or backend database.

# How to run it
https://yyyvetteeel.github.io/Reading-Garden/
Open it :)

# Known Limitations
Reading data is stored locally in the browser. It is not automatically synchronized across devices or browsers, and clearing the browser's site data may remove it.
